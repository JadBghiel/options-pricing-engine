# Benchmark results

Generated by `bash benchmarks/run.sh` (do not edit by hand). Median of several runs, Release
build (GNU 13.3.0), on 11th Gen Intel(R) Core(TM) i5-1135G7 @ 2.40GHz, 8 hardware threads, Python
3.12.3, NumPy 2.5.4, ope 0.1.0.

## From Python (pytest-benchmark)

What a Python user gets: each call includes the Python to C++ crossing. "NumPy" is the library
itself (`ope.price`, `ope.mc_price`, `ope.crr_price`). The tree has no multithreaded version:
each time step needs the one after it, so there is nothing to split.

| Workload | Pure Python | NumPy | C++ 1 thread | C++ 8 threads | C++ vs NumPy |
|---|---:|---:|---:|---:|---:|
| Black-Scholes, 100,000 calls | 44.8 ms | 7.7 ms | 7.2 ms | 2.5 ms | 3.1x |
| Monte Carlo, 1,000,000 paths | 582 ms | 35.6 ms | 37.5 ms | 11.4 ms | 3.1x |
| American put, CRR tree, 2,000 steps | 698 ms | 39.0 ms | 1.3 ms | n/a | 30.3x |
